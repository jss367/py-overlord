Ten strongest cards without runnable strategies

Recruiter, Goons, and Governor are my first picks. This is a qualitative ranking of strength for the cost, versatility, and ability to define a winning strategy under standard Dominion rules.

At the time of this assessment, before the Recruiter and Kitsune board search, all ten had zero explicit references across 135 runnable strategies. The catalog contained 610 cards, of which 405 were unused by that definition. These ten were individual candidates for future strategies, not a proposed ten-card kingdom. See the live coverage report for current counts.

Opinionated ranking; no simulations were run for this shortlist.

Scope and simulator limitations

The ordering is my judgment, not a tournament result or a universal buying order. Goons and Ambassador are included because the repository implements first-edition cards. Special rewards such as Loot and Prizes are excluded from this shortlist so each recommendation is an ordinary kingdom-card candidate.

“Unused” follows the catalog's coverage calculation: explicit gain, action, trash, exile, treasure priorities, and Way rules. It excludes condition-only references, custom decision code, automatic gains, and written guides. Publishing this guide does not change those usage counts.

Standard-rule strength needs separate simulator validation. During the original inspection, Kitsune's action option granted only one action; the published card grants two. That discrepancy was subsequently corrected and tested during the Recruiter and Kitsune board search. This shortlist does not certify all card implementations.

Recheck eligibility

Run from the repository root. Counts and eligibility are a snapshot and will change as runnable strategies are added.

PYTHONPATH=. python - <<'PY'
from dominion.reporting.strategy_pages import collect_rendered_strategies
from dominion.reporting.card_usage import collect_card_usage

names = ["Recruiter", "Goons", "Governor", "Ambassador", "Scrying Pool",
         "Black Market", "Kitsune", "Inventor", "Treasurer", "Villa"]
strategies = collect_rendered_strategies()
rows = collect_card_usage(strategies)
usage = {row.name: len(row.strategies) for row in rows}
print(len(strategies), "strategies;", len(rows), "cards;",
      sum(count == 0 for count in usage.values()), "unused")
for name in names:
    print(name, usage[name])
